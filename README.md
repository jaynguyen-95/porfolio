# Nguyen Dong Quy — Portfolio

## Publish with GitHub Pages

1. Upload every file in this folder to the root of your GitHub repository.
2. In the repository settings, enable GitHub Pages for the branch and folder you uploaded.
3. The site uses `index.html` as its home page. Keep `jay.jpg` and `portfolio-data.js` beside it.
4. Open `settings.html` on the published site to edit the content.
5. Download the updated `portfolio-data.js` from Settings, replace the repository copy, and commit the change to publish it.

## What Settings can edit

- Display name, introduction, and cover image
- Each Featured Works card title, short description, thumbnail, popup description, and gallery images
- What I do section introduction and service titles/descriptions
- FAQ introduction, questions, and answers

## Settings access and security

`settings.html` is not linked from the portfolio navigation, but it is not password-protected. GitHub Pages serves static files, so a password embedded in this page would not protect the content from someone who inspects the page source. Do not put private information here. For real access control, use a hosting service or authentication layer that supports protected pages.

## Files

- `index.html` — published portfolio homepage
- `portfolio-v2.html` — same portfolio under its versioned filename
- `settings.html` — content editor and export tool
- `portfolio-data.js` — editable portfolio copy, images, services, and FAQs
- `jay.jpg` — original hero cover image
- `.nojekyll` — tells GitHub Pages to serve files without Jekyll processing
